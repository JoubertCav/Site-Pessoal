The conjugate replaces a point \(x\) by a slope \(p\). For each slope, it records the highest affine function \(x\mapsto px-f^*(p)\) that remains below \(f\). Biconjugation reconstructs the closed convex envelope from all such supports.

11 · What can go wrong?

Conjugation closes and convexifies

The conjugate remembers support information, not arbitrary nonconvex detail.

The conjugate is not the inverse function

The variables have different meanings: \(x\) is primal position, while \(p\) is a slope or dual vector.

Correct relation. For smooth strictly convex \(f\), \(\nabla f^*=(\nabla f)^{-1}\), not \(f^*=f^{-1}\).

Biconjugation does not recover nonconvex bumps

The double-well function is replaced by its closed convex envelope.

Correct statement. \(f^{**}=f\) requires properness, convexity, and lower semicontinuity.

A finite supremum need not be attained

For \(f(x)=e^x\) and \(p=0\), \(f^*(0)=0\), but \(0\cdot x-e^x\to0\) only as \(x\to-\infty\).

Distinction. Finite conjugate value does not guarantee an argmax.

Extended values are essential

The conjugate of \(|x|\) equals \(0\) on \([-1,1]\) and \(+\infty\) outside.

Interpretation. \(+\infty\) records slopes for which no global affine minorant with finite intercept exists.
12 · Common mistakes

Precision traps

Most mistakes involve signs, domains, or confusing equality with universal validity.

Incorrect: “\(f^*(p)=\inf_x\{f(x)-px\}\).” Correct: \(f^*(p)=\sup_x\{px-f(x)\}\).
Incorrect: “The supporting line is \(px+f^*(p)\).” Correct: it is \(px-f^*(p)\).
Incorrect: “Fenchel–Young equality holds for all \(x,p\).” Correct: equality holds exactly when \(p\in\partial f(x)\).
Incorrect: “The conjugate of a convex function is always finite.” Correct: it may take the value \(+\infty\).
Incorrect: “\(f^{**}=f\) for every function.” Correct: \(f^{**}\) is the closed convex envelope below \(f\).
